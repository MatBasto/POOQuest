# Revisión de usabilidad

No requiere migraciones ni cambios de variables. Prueba primero en una carpeta separada o rama de trabajo. No ejecutes seed.sql.

## Comprobaciones antes de publicar
- Con una cuenta nueva, localiza la primera misión desde Inicio. Comprueba que el mapa informa del avance y que Territorios permite explorar.
- En selección única, múltiple, clasificación y secuencia, lee las instrucciones antes de responder. Comprueba que el botón solo se activa cuando hay una respuesta para revisar. En secuencia, deshaz un paso y corrige el orden.
- Provoca un error, corrige la respuesta y comprueba que el intento previo sí cuenta para las estrellas. Abre el repaso y confirma que las instrucciones siguen visibles y que no duplica XP.
- En Java, prueba error de compilación, salida incorrecta y éxito. Verifica que el código se conserva tras cada error. Prueba un fallo del servicio solo en local.
- Usa Tab y Enter para comprobar el enlace al contenido, el foco, las acciones y la navegación. Revisa a 360 px y con sonido desactivado.
- Ejecuta npm ci, npm test, npm run test:e2e y npm run build. No publiques si falla alguno.

Para comparar sesiones, repite las mismas tres tareas con el siguiente participante, sin indicar dónde pulsar. Registra si completó cada tarea, si necesitó ayuda y qué hizo después de un error. Estos son casos por verificar, no resultados de ejecución.
