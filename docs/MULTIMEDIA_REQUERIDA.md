# Multimedia requerida
El aplicativo funciona sin archivos externos porque los recursos conceptuales principales se generan con CSS/Motion. Si se desea acercar la versión final a los mockups, agregar estos archivos dentro de `public/media/`:

| Archivo sugerido | Uso | Formato recomendado | Tamaño aproximado |
|---|---|---|---|
| `login-hero.webp` | Fondo/ilustración de la pantalla de acceso | WebP, 16:9 o vertical | <= 350 KB |
| `abstraccion.webp` | Ilustración del módulo | WebP/SVG | <= 150 KB |
| `encapsulamiento.webp` | Ilustración del módulo | WebP/SVG | <= 150 KB |
| `herencia.webp` | Ilustración del módulo | WebP/SVG | <= 150 KB |
| `polimorfismo.webp` | Ilustración del módulo | WebP/SVG | <= 150 KB |
| `badge-primer-paso.svg` | Insignia opcional | SVG | <= 40 KB |
| `badge-explorador.svg` | Insignia opcional | SVG | <= 40 KB |
| `success.mp3` | Sonido breve al completar reto, opcional | MP3/OGG | <= 80 KB |

No uses imágenes con texto incrustado para explicar conceptos: el texto debe seguir siendo HTML para conservar legibilidad y accesibilidad. Si no agregas multimedia, la interfaz mantiene el diseño con gradientes, emoji e ilustraciones animadas construidas en código.
